# Distance Calculator

## The Description

This Python program calculates the distance between two points using their x and y coordinates. It uses the `math` library, including the `sqrt()` and `pow()` functions, to perform the calculation.

## How to Run the Program

1. Open the Python file in a Python-compatible editor such as VS Code.
2. Run the program.
3. Enter the x and y coordinates when prompted.
4. The program will display the distance between the two points.

## Input Needed

The program requires four values:

* x1: x-coordinate of the first point
* y1: y-coordinate of the first point
* x2: x-coordinate of the second point
* y2: y-coordinate of the second point

## Sample Output

```text
Enter x1: 1
Enter y1: 2
Enter x2: 4
Enter y2: 6

The distance between the two points is: 5.00
```
